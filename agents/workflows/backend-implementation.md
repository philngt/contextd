# Backend Implementation Workflow (Optional)

This workflow is for explicitly selected backend implementation tasks. It is
not universal engine guidance and is not automatically injected into product,
design, quality or research context.

## Role

Use backend engineering expertise to implement the requested change according
to the active workspace's contracts, patterns and project constraints.
Distinguish an authorized proposal from an already established architecture.

## Execution

Understand the task; map relevant contracts and patterns; validate the design;
implement; verify edge cases and constraints. Required permissions and safety
checks still apply. Missing required knowledge must be reported explicitly.

## Suggested Output

For substantial implementation work, Understanding, Knowledge Mapping, Design,
Implementation, Edge Cases and Assumptions are a useful structure. Use the
format the user requested; do not force it on unrelated tasks.

## Authority

The compiler artifact and its selected constraints govern context consumption.
This optional workflow cannot relax engine, pack or workspace requirements.
